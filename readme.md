## 4주차 반응형 수정

### 확인할 문제
작은 화면에서 메뉴, 기능카드, 이메일 폼이 좁여 보였다

### 수정한 내용
- viewport 메타 태그를 추가했다.
- 콘텐츠에 width와 max--width를 함께 사용했다.
- 기능 카드 목록을 반응형 grid로 변경했다.
- 768px 이하에서 메뉴, 카드, 폼을 한 열로 구성했다.

### 확인할 화면 너비
1100px / 769px / 768px / 390px


## 5주차 폼 제출에 반응하는 화면 

### 유저의 행동
가을 소식 받기에 이메일을 입력하여 구독 신청을 한다.

### 화면 변경점
이메일 입력 후 버튼 클릭 또는 엔터 입력시 
- 버튼의 글자, 색이 바뀐다
- 신청 완료를 알리는 메세지를 추가한다. 
- 색의 변화로 처리되었음을 알린다.

### 사용한 코드
if 조건문과 DOM으로 html요소를 찾는다.

## 6주차 이벤트 처리와 동적 구현

### 유저의 행동
- 가을 활동의 내용 탭을 클릭하고 변화를 확인한다.
- 다크테마로 바꾸기, 참가자 정보, 정보 동의 탭을 누르고 변화를 확인한다.

### 화면 변경점
- 탭을 누를 시 생기거나 사라진다.
- 입력에 따른 변화를 실시간으로 확인한다.
