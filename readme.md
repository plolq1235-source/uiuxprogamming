## 4주차 반응형 수정

### 확인할 문제
작은 화면에서 메뉴, 기능카드, 이메일 폼이 좁여 보였다

### 수정한 내용
- viewport 메타 태그를 추가했다.
- 콘텐츠에 width와 max--width를 함께 사용했다.
- 기능 카드 목록을 반응형 grid로 변경했다.
- 768px 이하에서 메뉴, 카드, 폼을 한 열로 구성했다.

### 확인할 화면 너비
1100px / 769px / 768px / 390px


## 5주차 폼 제출에 반응하는 화면 

### 유저의 행동
가을 소식 받기에 이메일을 입력하여 구독 신청을 한다.

### 화면 변경점
이메일 입력 후 버튼 클릭 또는 엔터 입력시 
- 버튼의 글자, 색이 바뀐다
- 신청 완료를 알리는 메세지를 추가한다. 
- 색의 변화로 처리되었음을 알린다.

### 사용한 코드
if 조건문과 DOM으로 html요소를 찾는다.

## 6주차 이벤트 처리와 동적 구현

### 유저의 행동
- 가을 활동의 내용 탭을 클릭하고 변화를 확인한다.
- 다크테마로 바꾸기, 참가자 정보, 정보 동의 탭을 누르고 변화를 확인한다.

### 화면 변경점
- 탭을 누를 시 생기거나 사라진다.
- 입력에 따른 변화를 실시간으로 확인한다.

# 독서소모임 가을

## 사용자와 목표
- 사용자 : 소모임에 관심이 있고 참여하고자 하는 사람
- 목표 : 가입에 필요한 정보를 입력하고 입력한 내용을 확인한다.
## 사용자의 흐름
1. 정보활용에 동의하고, '가을 참가하기'를 누른다.
2. 가장 좋아하는 책을 입력한다. 비어있으면 같은 단계에서 안내를 받는다.
3. 1년간 읽은 책의 권 수를 선택하고 필요하면 선호하는 모임 시간 선택을 포함한다.
4. 가장 좋아하는 책의 장르를 선택한다.
5. 가장 좋아하는 책, 1년간 읽은 책 권 수, 선호하는 모임 시간 설정, ??을 확인하고 수정하거나 완료한다.
6. 설정 완료안내를 확인하고, 필요하면 다시 설정한다.

## 인터랙션 시나리오
1. 소모임 참가신청 시작과 정보활용 안내
- 행동, 이벤트 : 정보활용 동의 체크박스를 선택하고 '소모임 참가신청 작성하기'를 선택한다.
- 조건 : 정보활용동의가 선택되었는가?
- 반응, 다음상태 : 동의 선택 전에는 버튼을 누를 수 없다. 동의 후 클릭하면 사용 목적을 안내하는 팝업이 열린다.
                팝업에서 돌아가기를 누르거나 esc를 누르면 동의를 해제하고 시작화면에 남는다.
                '동의하고 참가신청 작성하기'를 누르면 가장 좋아하는 책을 입력하는 화면을 연다.

2. 책 제목 입력
- 행동, 이벤트 : 가장 좋아하는 책 제목을 적고 '선호하는 장르 선택'을 클릭한다.
- 조건 : 앞뒤 공백을 지운 제목이 비어있는가?
- 반응, 다음상태 : 비어있으면 같은 화면에 오류를 표시하고 입력창에 초점을 둔다.
                값이 있으면 저장하고 선호하는 장르 선택으로 이동한다.

3. 1년간 읽은 책 권 수, 시간 선택
- 행동, 이벤트 : 권 수를 선택하고 원하면 선호하는 모임 시간을 선택한다. 
- 조건 : 선호하는 시간을 선택했는가? 
- 반응, 다음상태 : 선호하는 시간을 선택했을 때만 시간, 요일 선택지를 보여준다. 

4. 선호하는 장르 선택
- 행동, 이벤트 : 가장 선호하는 장르를 선택한다. 
- 조건 : 장르를 선택했는가?
- 반응, 다음상태 : 장르를 선택했을 때 내용 확인으로 넘어간다.

5. 내용 확인
- 행동, 이벤트 : 선호하는 책 제목, 권 수, 시간, 장르를 읽고 '수정하기' 또는 '설정 완료하기'를 클릭한다.
- 조건 : 수정인가? 완료인가?
- 반응, 다음상태 : 수정하면 기본 값을 유지하고 조건 선택으로 돌아간다. 완료하면 완료 안내로 이동한다.

6. 완료와 다시 설정
- 행동, 이벤트 : 완료 안내를 읽고 필요하며 '다시 설정하기'를 클릭한다.
- 반응, 다음상태 : 새 설정의 제목, 권 수, 시간, 장르 상태를 초기화하고 제목 입력부터 다시 시작한다.
                이미 확인한 정보 활용동의와 다른 기능을 유지한다.
